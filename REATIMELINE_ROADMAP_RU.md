# ReaTimeline Notes — Development Roadmap v0.1 (RU)
Дата: 2026-11-09
Рабочий репозиторий: `https://github.com/patch-34/reatimeline-notes` (branch `main`)
Исходник: ReaNotepad v0.6.2, commit `cc3e2a0714c15e22de8f9255117986f91c2c9a31`.
Основная ветка ReaNotepad не изменяется.

## Принципы
- Два независимых скрипта; без автоматического слияния с ReaNotepad.
- REAPER — источник истины для маркеров, линий и привязок.
- Заметки Project / Track / Item сохраняют оригинальных владельцев и хранилища.
- Единый список заметок — способ отображения, а не копирование данных.
- Сначала безопасное чтение и тестирование, затем запись с Undo.
- Позиции хранятся в исходной точности; форматирование до 0.001 с — только отображение.

## Контрольные этапы
- [x] **G0 / REAPER API Probe:** чтение 2 линий, 12 маркеров; определение изменения позиции и переноса из линии 0 в линию 1 на REAPER 7.83/OSX64. Проверка записи и переименования линий ещё не проводилась.
- [x] **G1 / Read-only native browser:** отдельный Lua-форк, маркеры видны автоматически по линиям; изменения отображаются в списке; заметки работают как раньше. Проверка в REAPER 7.83 на macOS Intel успешно выполнена пользователем.
- [ ] **G2 / Groups ↔ ruler lanes:** G2.1 (принят по результатам проверки REAPER 7.83 / OSX64): привязка по GUID, drag/drop на заголовок группы, перенос через контекстное меню, чтение внешних перемещений, переименование линий, native Undo/Redo. G2.2 (в планах): цвета, создание/удаление линий с подтверждениями и дополнительные проверки.
- [ ] **G3 / Unified notes:** Project / Track / Item в общем списке без выпадающего выбора владельца; сохранение исходных заметок и функций.
- [ ] **G4 / Conversion:** маркер ↔ заметка, массовый импорт всех маркеров, отсутствие дубликатов, согласованный Undo/Redo.
- [ ] **G5 / UX + time formatting:** контекстные кнопки конвертации, визуальные различия объектов, время по проекту / HMS.ms / seconds.ms / SMPTE / beats.
- [ ] **G6 / Reliability + release:** тесты проектов с множеством маркеров, переключение проектов, смена ruler lane, Undo/Redo, восстановление, производительность, отдельный пакет и ReaPack после согласования.

## G1 — критерии приёмки
1. Запустить `ReaTimeline_Notes.lua` вместе с REAPER 7.83 и ReaImGui 0.10+.
2. Проверить, что 12 маркеров автоматически показываются в двух группах без импорта.
3. Переместить маркер из одной линии в другую: после обновления он отображается в другой группе.
4. Изменить имя и положение маркера: отображение обновляется.
5. Переименовать ruler lane: проверить название группы (API чтения имени требует отдельной проверки).
6. Убедиться, что чтение маркеров не создаёт Undo, не изменяет проект и не создаёт копии.
7. Открыть заметки в обычном проектном режиме и проверить отсутствие регрессий.
8. Убедиться, что изменения настроек UI не затрагивают предпочтения оригинального ReaNotepad.
9. Подтвердить отсутствие ошибок в консоли REAPER, включая переключение между проектами.

## Ограничения G1
- Маркеры только отображаются; обратный перенос из UI в REAPER появится в G2.
- Заметки пока используют исходный selector Project / Track / Item; единый список — G3.
- Хранилища самих заметок намеренно совпадают с ReaNotepad, чтобы оставаться привязанными к оригинальным REAPER объектам. Не редактировать одного и того же владельца одновременно в двух запущенных скриптах.
- Изолированы prefs, ImGui context/window ID и recovery folder; исходные документные заголовки и ключи нот оставлены для совместимости.

Тестировать только на копии проекта. До завершения G2 не объединять dev/g2-lane-sync с main.

### G2.1 — Undo/Redo focus fix (v0.2.0-dev.2)

- При последнем действии с маркерами сочетания Cmd+Z / Cmd+Shift+Z относятся к истории REAPER.
- При редактировании заметок используется прежняя история заметок. Истории намеренно не объединены.
- Команды «REAPER Undo» / «REAPER Redo» доступны прямо в панели маркеров и в Edit.
- При активном текстовом поле и всплывающем меню глобальная маршрутизация Undo не перехватывает ввод.
- Все операции с историей REAPER затрагивают весь текущий проект, а не только маркеры.
- Код исправления проверен автоматическими тестами маршрутизации и имитацией REAPER API; требуются реальные тесты фокуса окна в REAPER 7.83/OSX64.
